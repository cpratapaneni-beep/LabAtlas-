## Coverage

## ForagerOne -- what institutions praise (from campus pages)
- One searchable place for on-campus research openings; faculty can find students; interdisciplinary discovery. (Emory, Baylor 2025, UK, Wayne State 2025) [Data]
- Messages route to university email, so faculty don't have to monitor another inbox. (Mizzou FAQ) [Data]
- Faculty profiles are auto-created from existing web pages, which lowers setup effort. (Mizzou, UK via Scholars@UK, Wayne State) [Data]

## ForagerOne -- friction signals (inferred, not complaints)
- New faculty "will not have an auto created file" and must be onboarded at orientation. (Mizzou FAQ) So coverage lags for new hires. [Data]
- Institutions run faculty demo workshops (Wayne State Dec 2024; Eastern Michigan faculty-development workshop), which suggests faculty adoption takes deliberate effort. [Data -> Inference]
- Missing: any public complaint data. Don't infer dissatisfaction from absence. [Honesty note]
